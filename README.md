#NurseAssist

To run: 

Navigate to merged_branch. 

Terminal 1:
Cd server 
Npm install
Node seed.js (only need to do this once to seed data)
Node index.js

Terminal 2:
Cd client
Npm install
Npm start
If prompted to run on a different port press Y

App should run from there
